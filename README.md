# 📞 Customer Service Dashboard – Excel

## 📌 Project Overview

This project is an interactive Customer Service Dashboard created using Microsoft Excel.

The dashboard provides insights into customer satisfaction, agent performance, customer interactions, and different contact types. It helps analyze customer service data and identify performance trends through interactive visualizations.

## 📊 Dashboard Preview

![Customer Service Dashboard](Screenshot%20Dashboard.png)

## 🎯 Project Objectives

- Analyze customer satisfaction levels.
- Compare the performance of different customer service agents.
- Analyze the number of customer interactions.
- Compare different contact types.
- Track customer satisfaction over time.
- Analyze daily customer interactions.
- Create an interactive and user-friendly dashboard.

## 📈 Dashboard Analysis

### 👨‍💼 Agent Performance
- Average customer satisfaction by agent.
- Number of interactions handled by each agent.
- Comparison of agent performance.

### 📞 Contact Type Analysis
- Number of interactions by contact type.
- Average customer satisfaction by contact type.
- Comparison between Complaint, Query, and Request interactions.

### 📅 Time-Based Analysis
- Day-wise customer satisfaction.
- Day-wise customer interactions.
- Identification of changes and trends over time.

## 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

- Agent Handled
- Contact Type

These filters allow users to dynamically explore the dashboard and analyze specific segments of the data.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization
- Dashboard Design
- Conditional Formatting

## 💡 Key Insights

- Customer satisfaction varies across different customer service agents.
- Request-type interactions have a higher interaction volume compared with other contact types.
- Customer satisfaction can be compared across different contact types.
- Daily interaction volume fluctuates significantly over time.
- Interactive filters make it easier to analyze individual agents and contact categories.
